# 工时记 · 白夜班工时与加班费

一个只给手机用的工时记录 PWA：纯静态 HTML/CSS/JS，Python 起服务，数据只存本机，离线可用。

版本与改动记录见 [CHANGELOG.md](CHANGELOG.md)（当前 1.3.0）。

## 功能

- 月历首页：日历 + 本月加班费概览 + 7 项汇总，底部悬浮导航，日历页「＋」快速记今天
- 每日工时：起止时间 − 休息时长，可按 15/30/60 分钟取整
- 加班分档：工作日超 8h 算加点 1.5×；休息日 2×；法定节假日 3×
- 缺勤、请假：工作日休息自动算缺勤；年假、病假、事假、调休，支持 0.5 天
- 排休计划：只能排未来日期，当天显示「排」，日期过后自动转「休息」
- 抵缺勤后工时：`加班 + 加点 − 缺勤×8`，缺勤优先冲减休息日加班，三薪不抵扣
- 加班费：按倍率折算成金额，与工时账分开显示
- 节假日：内置 2025–2027 国务院安排，可自定义增删改，支持在线 JSON 更新
- 统计：月度汇总、公式拆解、计薪加班构成环形图、每日工时图、CSV 导出（明细已移除）
- 界面：深色 / 浅色主题，周一 / 周日开头，轻量页面切换与按压动效，尊重系统「减少动态效果」设置
- 备份：JSON 导出 / 导入，清空记录
- PWA：manifest、Service Worker、图标、离线缓存

## 启动

需要 Python 3.9+，不需要 Node。

```bash
cd worklog
python serve.py
```

默认监听 `0.0.0.0:8080`，启动后会打印：

```
本机:  http://127.0.0.1:8080
手机:  http://192.168.x.x:8080  (同一 Wi-Fi)
```

手机和电脑连同一个 Wi-Fi，浏览器打开「手机」那一行即可。

自定义端口：

```bash
python serve.py --port 9000
```

### 手机连不上？

1. 确认在同一个 Wi-Fi（不是访客网络 / 5G）。
2. Windows 防火墙弹窗时允许「专用网络」；或手动放行 8080 端口。
3. 电脑的局域网 IP 用 `ipconfig` 查看 IPv4 地址。

## PWA 安装（重要）

浏览器的规则：**只有 HTTPS 或 localhost 才允许注册 Service Worker 和安装 PWA**。

- 用 `http://127.0.0.1:8080` 在电脑上打开：可以安装、可以离线。
- 用 `http://192.168.x.x:8080` 在手机上打开：**可以正常记录，但不会出现安装按钮，也不能离线**。这是浏览器安全限制，不是代码问题。
- 想在手机上安装：把整个 `worklog/` 目录放到任意 HTTPS 静态站点（GitHub Pages、Netlify、Vercel、Cloudflare Pages、自己的服务器），手机访问 HTTPS 地址后即可「添加到主屏幕」。
- 已内置 `manifest.webmanifest`、`sw.js`、192/512/maskable/apple-touch 图标，部署后无需再改。

## 使用

1. 第一次打开先去「设置」填时薪（或月薪，按 ÷21.75÷8 折算）。
2. 回「日历」，点任意一天：
   - 状态：上班 / 休息 / 请假 / 排休（排休只对未来说）
   - **工作日选「休息」就是缺勤**，按 8h/天扣减（可选 0.5 天）；休息日/法定节假日选「休息」是正常休息
   - 上班：选班次、改起止、改休息分钟
   - 请假：年假 / 病假 / 事假 / 调休，选 0.5 或 1 天
   - 排休：一次排一天；当天显示「排」，日期过后自动转「休息」；工作日转休息会按缺勤 8h/天计，休息日/法定不扣
   - 日期类型：自动 / 工作日 / 休息日 / 法定节假日（手动改优先）。公司放假请把类型改成休息日，避免被算成缺勤。
3. 保存后，日历格子和底部汇总即时更新。
4. 月底去「统计」看加班费、抵缺勤后工时和每日工时图，可导出 CSV。

### 计费口径

| 日期类型 | 计费 |
|---|---|
| 工作日 | 8h 内 1×，超出部分 1.5× |
| 休息日 | 全部工时 2× |
| 法定节假日 | 全部工时 3× |

> 没有单独的「缺勤」状态：工作日状态选「休息」就按缺勤 1 天（或 0.5 天）扣减；休息日 / 法定节假日选「休息」是正常休息，不扣。若当天实际是公司放假，先把日期类型改成「休息日」，否则会被算成缺勤。
>
> 完全没填的工作日会保持「未填」，不会自动算缺勤，避免忘记录一天就被扣钱。

节假日表里还有「休息 2×」（长假里调休出来的工作日）和「补班」（调休上班的周末，按工作日算）。

缺勤 / 事假 / 调休按 8h/天，先冲减 2× 加班，再冲减 1.5× 加点，剩余记「欠班」；**法定 3× 工时不参与抵扣**。欠班只保留在结算结果里，界面不再单独展示，也不从三薪里扣钱。

日历汇总的「总工时」只算加班 + 加点，不含正常 8 小时；「抵缺勤后工时」才是冲减缺勤 / 事假 / 调休后的工时账（结算内部字段是 `ledger`）。

请假扣款：

| 类型 | 扣款 |
|---|---|
| 年假 | 0（带薪） |
| 病假 | 8h × 天数 × (1 − 病假工资比例) |
| 事假 | 8h × 天数（同缺勤，冲减加班） |
| 调休 | 0（冲减加班余额） |

## 数据与备份

- 存在浏览器 `localStorage` 的 `worklog:v1`，不上传任何服务器。
- 换手机、清缓存、卸载浏览器前，务必在「设置 → 数据」导出 JSON 备份。
- 换访问地址（例如从 `http://192.168.x.x:8080` 换成 HTTPS 域名）数据不互通，先导出再导入。
- 导入支持覆盖恢复；CSV 是 UTF-8 带 BOM，Excel 直接打开不乱码。

## 节假日更新

内置数据在 `js/holidays.js`，版本号 `HOLIDAY_VERSION`，目前覆盖 2025–2027。

两种更新方式：

1. **随应用更新**：改 `js/holidays.js`，提交推送即可。Service Worker 是网络优先的，用户刷新就会拿到新文件，不用再改 `VERSION`；`VERSION` 只是延迟缓存的名字，只有想一次性清空旧缓存时才动它。
2. **在线 JSON**：设置 → 节假日 → 填一个 JSON 地址，格式：

```json
{
  "version": "2028.1",
  "holidays": [
    { "date": "2028-01-01", "name": "元旦", "type": "statutory" },
    { "date": "2028-01-03", "name": "元旦假期", "type": "rest" },
    { "date": "2028-01-02", "name": "元旦调休", "type": "makeup" }
  ]
}
```

`type`：`statutory` 法定 3×、`rest` 休息 2×、`makeup` 补班。填好后点「检查更新」，或下次启动自动检查（每天最多一次）。

```bash

python tools/smoke_ui.py      # 用 DOM stub 跑 5 个页面与日记录 / 排休弹层
```

`tools/pylibs` 里是测试用的 QuickJS 轮子，不影响应用运行；不需要可以整个 `tools/` 删掉。
