## 1.3.0 — 2026-11-10

### 变更

- Service Worker 明确为**网络优先**：先请求网络，成功就返回最新内容并写回缓存，只有离线或请求失败时才回退到缓存。改完页面文件刷新即生效，**不再需要为了「更新缓存」去改 `VERSION`**。
- 所有同源请求统一带 `cache: 'no-cache'`，绕过浏览器 HTTP 缓存与 GitHub Pages 的 `max-age=600`，避免改动十分钟内仍显示旧文件。
- `VERSION` 升到 `worklog-1.3.0`（= 缓存名），一次性清掉旧缓存。
- 新增本更新日志文件，并在 README 中链接。

### 修复

- `SKIP_WAITING` 消息同时接受字符串和 `{ type: 'SKIP_WAITING' }` 两种写法，和 Cart Log、以及各浏览器的习惯统一。

## 1.2.0 — 首次记录（发布日期不详）

1.2.0 及更早的版本没有单独保存提交记录，下面是这一阶段的功能汇总：

- 月历首页：日历 + 本月加班费概览 + 7 项汇总，底部悬浮导航，日历页「＋」快速记今天
- 每日工时：起止时间 − 休息时长，可按 15 / 30 / 60 分钟取整
- 加班分档：工作日超 8h 按 1.5×，休息日 2×，法定节假日 3×
- 缺勤与请假：工作日休息自动算缺勤；年假、病假、事假、调休，支持 0.5 天
- 排休计划：只能排未来日期，当天显示「排」，日期过后自动转「休息」
- 抵缺勤后工时：`加班 + 加点 − 缺勤×8`，缺勤优先冲减休息日加班，三薪不抵扣
- 节假日：内置 2025–2027 国务院安排，可自定义增删改，支持在线 JSON 更新
- 统计：月度汇总、公式拆解、计薪加班构成环形图、每日工时图、CSV 导出
- 界面：深色 / 浅色主题，周一 / 周日开头，轻量页面切换与按压动效，尊重系统「减少动态效果」
- 备份：JSON 导出 / 导入，清空记录
- PWA：manifest、Service Worker、图标、离线缓存；可安装到桌面
